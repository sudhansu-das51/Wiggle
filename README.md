# 🧸 Wiggle - Premium Preschool & Daycare Web Application

A joyful, playful, and responsive web application built with modern web technologies, thoughtful micro-interactions, rich SVG cutaways, and interactive classroom experiences.

---

## ✨ Features

- **🎒 Interactive Programs**: Detailed age-appropriate tracks (Playgroup, Nursery, Jr. KG, Sr. KG) featuring curriculum highlights, learning goals, and daily schedules.
- **🏫 Cutaway School Building**: Interactive visual walkthrough of the facilities, grounds, and learning zones.
- **🎨 Warm Visual Identity**: Designed around playful aesthetics, hand-drawn ink outlines, sticker micro-interactions, and vibrant color palettes.
- **📅 Interactive Events & Calendar**: Yearly rhythms, celebrations, and workshops.
- **👩‍🏫 Dedicated Faculty & Team**: Teacher profiles and mission showcase.
- **📱 Responsive & Accessible**: Fluid typography, accessible contrast, and mobile-friendly navigation.

---

## 🛠️ Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Animations**: Anime.js & Canvas Confetti
- **Icons**: Remix Icons
- **Styling**: Vanilla CSS Design System with custom CSS custom properties (Ink, Bubblegum, Sunny, Sky, Meadow, Paper)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sudhansu-das51/Wiggle.git
   cd Wiggle
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

---

## 📦 Production Build

To build the application for production:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
